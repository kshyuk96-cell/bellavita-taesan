문구 검토 6
문구 대조 확인은 선택한 OCR 후보 한 건의 보내는 분·받는 분·인쇄 문구만 원문과 직접 대조해 기록합니다.
OCR 값은 덮어쓰지 않습니다. 사용자 확인값은 별도로 표시하고 공백 차이도 불일치로 표시합니다.
확인 후 분석 내용이 바뀌면 이전 확인을 자동 적용하지 않습니다. 고객 기본값이나 다른 주문으로 전달하지 않습니다.
같은 화면 반복, 프로세스 재시작은 새 주문 후보를 추가하지 않습니다.
동일 문구가 다시 나타나거나 같은 말풍선이 늘면 재전송·스크롤·별도 주문을 자동 단정하지 않고 검토 표시합니다.
주문번호를 명시한 수정·취소 요청도 대상 힌트만 보관하며 실제 주문이나 시트를 수정하지 않습니다.
결혼·행사 테스트 버튼은 합성 문구를 표시하고 사용자 클릭 시에만 클립보드에 복사합니다. 자동 전송하지 않습니다.
검토용 주문서 파일은 개인정보가 포함되므로 공개 프로그램에는 넣지 않습니다. 별도의 사용자 전용 파일을 준비해야 합니다.
기획 방 공유는 수동 테스트 허용을 선택한 뒤 사용자가 직접 실행해야 하며, 자동 백그라운드 감시와 분리됩니다.
로컬 검증: 단위 테스트 151개, 합성 주문 시나리오 300개, 동일 프레임 재생 1500회.
이는 실제 카톡 300건 검증이나 시트 입력 성공을 뜻하지 않습니다. 실제 Windows 확인은 별도로 진행합니다.
