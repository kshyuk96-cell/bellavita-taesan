압축을 푼 뒤 START_PANEL.cmd 실행.
Python 3.10 이상(tkinter 포함)과 requirements-windows.txt 구성이 필요합니다.
실행 시 설치 여부를 검사하며 실패해도 창이 바로 닫히지 않습니다.
고객방 설정 -> 등록 -> 저장 -> 방 목록 새로고침 순으로 선택하세요.
선택 방 읽기는 등록한 고객방의 대화 목록을 8초 안에 클릭해야 합니다.
첫 읽기는 기존 대화를 제외합니다. 새 메시지를 골라 한 건씩 분석합니다.
메시지 경계를 읽지 못하면 자동 합치지 않습니다. 주문 한 건을 직접 붙여넣을 수 있습니다.
분석은 로컬 텍스트 규칙입니다. 링크 조회, AI 주문 추론, 고객 기본값 학습, 시트 쓰기는 하지 않습니다.
연결 테스트는 기획 방과 전용 키만 사용합니다. 서버 답장은 고정 연결 확인 문구입니다.
화면 안내에 따라 기획 방 대화 목록/입력칸을 선택해야 하며 백그라운드 상시 감시가 아닙니다.
검토용 주문서 공유는 포함된 사본 21380행의 표시값 스냅샷을 기획에 보냅니다.
미확인 정보는 그대로 표시하며 최종 확정·실배송·청구 용도로 사용하지 않습니다.
전송 결과가 불명확한 경우 재시도하지 않습니다. 실제 말풍선을 확인해야 합니다.
클립보드에 이미지/파일/서식이 있으면 보호를 위해 전송을 중단할 수 있습니다.
토큰·대화 원문은 저장소나 서버에 올리지 않습니다. 서버로는 고정 테스트 문구와 번호만 보냅니다.
Windows에서의 통합 실행은 아직 현장 검증 전입니다.
