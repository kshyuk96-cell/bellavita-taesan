## CSV와 개인정보

CSV는 기존의 서명된 관리자 경로 뒤 `/orders.csv`에서 제공한다. 만료·잘못된 관리자 링크는 거부하고 다운로드 응답은 `private, no-store`를 유지한다. 파일에는 원주문금액을 표기하며 정산 잔액 파일로 취급하지 않는다. 연락처는 일부 가리고 내부 메모·서명 링크는 포함하지 않는다. 표 계산 프로그램의 수식으로 해석될 수 있는 값은 앞에 작은따옴표를 붙인다. UTF-8 BOM을 포함한다. 10,000건 초과 시 검색 조건을 좁히도록 안내하고 일부만 몰래 내보내지 않는다.

화면 연락처 가림은 기본 노출을 줄이기 위한 것이다. 인증된 관리자에게 전달된 HTML의 검색용 값·연락처 데이터가 제거됐다는 뜻은 아니다. DOM을 분석할 수 있는 관리자에게 전화번호 접근을 막는 별도 권한 경계로 취급하지 않는다. 전화번호 원문으로 검색했더라도 가린 번호를 검색 강조로 드러내지 않는다.

검색 조건과 펼침 정보는 URL에 있으며 localStorage/sessionStorage에 고객정보를 저장하지 않는다. 검색어에 고객정보를 넣은 관리자 URL은 외부에 공유하지 않는다. 펼침 복귀는 해당 주문의 상세 인덱스 최대 12개를 복원한다. 주문 상세 구조가 변경되는 작업 뒤에는 올바른 항목이 열렸는지 다시 확인한다. 검색 결과에서 변경한 주문이 사라지면 기존 ‘변경한 주문 바로 열기’ 링크에도 펼침 조건을 전달한다.

## 통합 파일과 경로

- `shop_admin_queries.py`: 공용 필터와 SQL 조각 재사용, 정렬, 조건 표시·내보내기 안내, 복귀 정보 검증.
- `shop_admin_review.py`: 안전한 강조, 연락처 표시, 설치 정보, 상태 배지, 조건별 안내, CSV 생성.
- `shop_admin_review.js`: 전화번호 토글·다시 가림, 복사 대체, 상세 펼침 정보 전달과 복원. 네트워크 호출이나 브라우저 저장소 사용 없음.
- `shop.py`, `shop_admin_team.py`, `shop_admin_layout.py`: 관리자 화면에 위 기능 적용. 공용 레이아웃이 JS 파일을 읽으므로 함께 배포한다.
- `shop_admin_workflow.py`: 저장 검색에 정렬 유지, 페이지·일시적인 상세 펼침 정보 제외.
- `agent.py`: 기존 관리자 인증·다운로드 응답 처리 안에 CSV 경로 추가.
- DB 스키마나 외부 계정 설정·새 서비스는 필요하지 않다. 기존 서명·권한·서버 주문 검증·결제 로직은 재사용한다.

기본 정렬은 기존 동작을 유지한다. ‘주문 최신순’과 ‘행사 임박순’은 사용자가 선택한다. 상태 배지는 제작 재개나 취소 승인을 실행하지 않는다.

## 검증

독립 합성 DB와 로컬 HTTP에서 실행했다. 주문 상태·원본 details의 전후 값을 비교했고 새 관리자 기능으로 변경되지 않았다. 브라우저에서 업무 등록은 합성 데이터에만 실행했다. 실제 결제·메시지·영수증·운영 원장은 호출하지 않았다.

```sh
.venv/bin/python -m unittest discover -s tests
PYTHONPATH=tests .venv/bin/python -m unittest test_admin_review_batch02 test_admin_team
PYTHONPATH=tests .venv/bin/python tests/browser_admin_review_batch02.py
PYTHONPATH=tests .venv/bin/python tests/browser_admin_usability.py
PYTHONPATH=tests .venv/bin/python tests/browser_admin_workflow.py
```

전체 회귀 184개 통과. 마지막 표시 조정 후 관련 테스트 10개와 새 브라우저 시나리오를 재확인했다. 새 시나리오는 390/1280px, 기존 사용성·인계는 375/1280px에서 통과했다. 검색 결과 70건이 3페이지로 나뉘어도 CSV에 70건 모두 포함되는지, 필터가 CSV에도 적용되는지, 수식 방지·다운로드 권한·오류 복귀·가림·복사 대체를 확인했다. 상세 근거는 [2차 검증 기록](validation/admin-batch-02.json)을 사용한다.

운영 DB 검사나 실제 가맹점 성공, 원격 관리자 화면 검증은 이번 결과에 포함하지 않는다. 기존 출시 검증과 이번 추가 개발 소스의 배포 상태를 구분한다.

패치는 1차 커밋 `ccfb4bb62d87e6167074bde47d52729eea522537` 이후의 증분이다. 다른 플랫폼에 옮길 때는 위 모듈과 기존 관리자 DOM·서명 인증·공용 필터 계약을 함께 맞춘다. 이번 묶음에 결제 전 UI 1차 소스를 다시 중복 적용하지 않는다.
