# 상시 클라우드 호스트 결정 준비

이 문서는 운영 배포·새 자원·추가 결제 승인이 아니다. 현재 실제 개발·독립 검토는 namespace 격리를 검증한 Codex 클라우드 환경에서만 시험한다. 형님 PC 상시 실행이나 QR 페어링은 요구하지 않는다.

## 확인한 계정과 가격

Render MCP는 연결돼 있지만 선택된 워크스페이스는 없다. 조회 가능한 후보는 `Simba's workspace` (`tea-dbqjaul6e07s73fcqmo0`) 1개다. 후보가 하나라는 이유로 선택하거나 기존 서비스를 변경하지 않았다. 따라서 기존 자원의 재사용 가능성·현재 요금제·지역·유료 자원 보유 여부는 아직 확인하지 않았다.

2026-11-16에 공식 [컴퓨트 계획](https://render.com/docs/compute-plans), [가격](https://render.com/pricing), [디스크 문서](https://render.com/docs/disks)를 직접 읽었다.

| 준비안 | 공식 표시 비용 | 미확정 범위 |
| --- | --- | --- |
| 제어 API용 최소 유료 서비스 `0.5c-512mb` | 월 7달러 | 실제 제어 API 부하·기존 자원 재사용 여부 |
| 영속 디스크 1GB 예시 | 월 0.25달러 | 실제 DB·소스·결과물 용량에 따라 산정 필요 |
| 개발 작업자용 `1c-2g` 비교값 | 인스턴스당 월 25달러 | 이 사양을 선택하거나 생성한 것은 아님 |

제어 API 최소 서비스와 1GB 디스크를 신규 사용한다고 가정하면 알려진 부분은 월 **7.25달러**다. 전체 운영 견적이 아니다. 작업자·외부 보관소·트래픽·세금·계정 플랜·모델 비용은 별도다. ChatGPT 구독과 API 비용도 별개이며 이번 묶음에서 유료 API를 호출하거나 충전하지 않았다.

## 현재 코드를 바로 배포할 수 없는 이유

현재 정식 실행기는 실제 네트워크/PID namespace 격리와 독립 런타임을 요구한다. Render의 해당 후보에서 이 기능이 가능한지 측정하지 않았다. 격리를 일반 subprocess 실행으로 낮춰서 배포하지 않는다. 제어 API만 분리해 작은 서비스에 놓으려면 원격 작업자 연결을 추가 검증해야 하며, 현재 통합 실행기를 그대로 월 7.25달러에 운영할 수 있다는 뜻이 아니다.

디스크가 붙은 서비스는 단일 인스턴스이며 자동 수평 확장·무중단 배포를 사용할 수 없다. 상태는 마운트 경로 안에 저장해야 한다. SQLite는 파일 스냅샷만 믿지 않고 온라인 백업과 별도 복원 검증을 사용한다. 기존 `ops/taesan-governance.service.example`는 namespace를 지원하는 클라우드 Linux 호스트용 검토 예제이며 설치하지 않았다.

## 운영 전환 전에 고정할 항목

1. 형님이 사용할 Render 워크스페이스 또는 별도 클라우드 Linux 호스트 지정.
2. 정확한 서비스·지역·실행 코드 커밋·접근 주소·자동 배포 여부.
3. namespace 격리·Node/Python 런타임·개발/검토 프로필 분리의 실제 호스트 검사.
4. 영속 DB·소스·검토 결과물·비밀 보관 위치와 백업 보존·오프호스트 보관 정책.
5. 인증 갱신 담당 경로와 만료 시 실행 차단·관리자 보고 규칙.
6. 전체 비용 상한·운영 전환 범위·중단 및 복구 절차를 묶은 최종 승인 패킷.

워크스페이스 선택, 실제 격리 측정, 전체 비용 확정 전에는 호스트 준비 완료로 표시하지 않는다. 24시간 가용성도 아직 검증하지 않았다.
