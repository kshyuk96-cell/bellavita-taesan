# Measured readiness and recovery batch

This batch adds infrastructure controls to the four-project worker manager. It excludes the separately developed tester engine and does not deploy, merge main, start native model work, alter customer services, charge APIs or create resources.

## Implemented behavior

- Owner-pinned local host measurements now participate in the actual new-work reservation and core-start boundary. Missing adapters cannot bypass durable requirements. Failed/stale observations replace prior healthy status; cached old success cannot overwrite a later failure.
- Governance service runtime holds a cooperative process-lifetime lock for the same private local control database before starting its HTTP and manager threads. Cross-host coordination remains the existing fenced database leader/action protocol; a local file lock is not a distributed lock.
- Recovery inspection groups unresolved actions, host assignments, expired worker/review leases, supervision jobs and restored-authority quarantine. A timeout never proves a worker stopped. Foreign-scope/actor/epoch leaders cannot hide unresolved work. Inspection itself never replays, kills or reconciles a task.
- An AES-256-GCM encrypted backup interface supports create-only trusted transports, durable uncertain outcomes, ciphertext/AEAD/SQLite integrity checks and restoration to a new quarantined database. A private local backend was exercised. No actual remote backend or disaster-loss receipt recovery is claimed; receipt catalog/key custody and off-host verification remain open.
- Atomic owner-only registration accepts up to 20 inactive review-only project metadata entries, with exact prior revision/fingerprint and idempotent request scope. It does not expand manager credentials, worker profile enrollment or the host project map.
- Authenticated API reports group current exceptions and count 12 observed prerequisite categories per selected project. Unknowns are unmet. Coverage is an auditable met/total count; percentage and always-on verification remain unavailable. No report is sent externally.

Independent review found and fixed a host-only legacy-start bypass, raw/encoded key material in cleartext backup labels, foreign-leader recovery misclassification and stale-positive host evidence overwriting a newer negative. Regression cases cover each.
