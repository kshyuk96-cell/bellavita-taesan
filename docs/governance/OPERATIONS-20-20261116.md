## 공통 배정 경계

`OperatingBudget` 정책 설치는 소유자만 가능하다. 신뢰된 호스트 관찰자의 인증 상태만 저장한다. 갱신 콜백 전 영속 sequence를 발급하고 완료 후 요청자·설정·sequence·관찰 시각을 확인해, 늦게 도착한 이전 ready 응답이 최신 장애를 덮어쓰지 못하게 한다. 관찰 유효 시각은 캐시 수명이며 OAuth 자격 증명의 만료를 추정한 값이 아니다.

`ContinuousManager`는 새 start/approve_next의 실행 의도 기록 전에 예약을 확보한다. `ThreeTier.start/approve_next` 공통 지점도 정확한 예약·살아 있는 실행 의도·요청자·설정·정책·신뢰된 실행 context를 확인한다. 기존 직접 API에는 이 context를 입력하는 필드가 없다. 재시작 후 정책은 있지만 등록된 관리기가 없으면 실행을 막는다. 일반 worker claim도 정책이 설치된 관리 프로젝트를 우회하지 못한다.

정상 기술 승인에서는 정확한 독립 검토 근거로 미완료 한도를 반환한다. 재시작 등으로 반환을 놓친 경우에는 인증된 `budget/reconcile`이 같은 근거를 확인한다. 검토 증거 변조·권한 회수·불확실 결과는 단순 시간 경과나 응답 코드만으로 한도를 반환하지 않는다. 최초 정책 설치 이전 업무까지 실제 프로세스 사용량으로 측정했다는 뜻은 아니며, 기존 전역/프로젝트 실행·경로 예약 제한도 계속 적용된다.

## 중앙 운영 API

기존 인증·JSON 제한·CSRF 경로 아래 POST 접두사는 `/v1/representative/runtime/governance/control/operations/`이다. 메서드와 정확한 필드는 `operations_control_api.py`에서 검증한다.

- `preflight`, `owner-packet`: 선택한 네 고객의 사전 조건과 하나의 결정 패킷
- `report`, `batches`: 묶음 보고와 오래된 승인 목록의 별도 cursor
- `budget/report`, `budget/install`, `budget/auth`, `budget/reconcile`: 정책·상태 조회와 제한된 제어
- `artifacts/register`, `artifacts/get`: 등록된 관찰 소스의 해시 메타데이터 저장·조회

요청에 콜백·호스트 경로·원문 증거·인증 성공 플래그·실행 명령을 넣을 수 없다. 아티팩트 보관 기간은 메타데이터의 논리적 만료이며 실제 원본 삭제를 뜻하지 않는다. 묶음 보고는 관찰 당시 snapshot이므로 새 상태를 보려면 새 request_key를 사용한다. 업무·배치·보고 입력이 일부만 조회되면 완료 상태로 표시하지 않는다.

## 조건부 상시 운영 전환안

[검토용 구성](../../ops/governance-transition-plan.json.example)은 Simba’s workspace의 기존 고객 서비스를 전용하지 않고 별도 관리기 1개와 개발/검토 실행 위치를 분리한다. 지역 제안은 Oregon이다. 이 JSON은 런타임 설정이나 Blueprint가 아니며 자원 생성 권한도 제공하지 않는다.

공개 가격 기준 예시는 관리기 `0.5c-512mb` 월 $7, 개발자·검토자 `1c-2g` 각 월 $25, 디스크 1+5+5=11GB × $0.25=$2.75로 **추가 월 $59.75**이다. 이는 실측 사용량이나 최종 청구액이 아니다. 작업공간 요금·세금·전송량·별도 백업·구독/API 요금·초과 사용은 제외한다. 가격 출처는 [Render 가격](https://render.com/pricing), [Compute plans](https://render.com/docs/compute-plans), [Persistent disks](https://render.com/docs/disks)이다.

이 구성은 Render에서 필요한 namespace 격리가 실제 허용되는 경우에만 검토할 수 있다. 현재 MCP 연결은 원격 shell 실행을 제공하지 않으며 기존 서비스 6개 중 관리기로 검증된 대상은 없다. 실제 메모리·디스크 요구, 호스트 실행 경로, 실제 재시작 후 상태, 호스트 밖 백업·복원도 확인해야 한다. 따라서 이 예시 비용으로 지금 배포할 수 있다고 보장하지 않는다. 단독 관리기만의 $7.25 예시는 전체 개발 실행 비용이 아니다.

전환 중 실패하면 새 배정을 멈추고 uncertain journal과 원본을 보존한다. 복구본은 격리 상태로 열고 현재 권한·소스·작업자 종료·독립 근거를 확인하기 전 재생하지 않는다. main 병합, 새 유료 자원, 상시 서비스 설치, 운영 쓰기는 수행하지 않았다. 이 묶음으로 90% 운영 통제에 도달했다고 주장하지 않는다.
