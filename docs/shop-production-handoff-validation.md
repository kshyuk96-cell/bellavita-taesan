## 완료한 범위

- 결제 확인과 같은 트랜잭션에서 고유 주문번호당 제작 접수 한 건 생성.
- 사진이 필요한 주문은 대표의 사진 검토 전까지 전달 보류.
- 인증된 공장 수신기가 원장 사본과 제작 대기열을 한 트랜잭션에 저장.
- 선점 만료·재전달·응답 유실·동시 수신에서도 주문번호별 한 행만 유지.
- 취소·부분취소가 들어오면 아직 전달하지 않은 제작은 보류하고, 이미 전달한 건에도
  별도 보류 접수를 전달. 늦은 기존 접수나 오래된 금액이 보류·취소 누계를 되돌리지 않음.
- 원장 사본에 원결제금액·취소 누계·잔액 구분. CSV 수식 입력 이스케이프.
- 수신 확인 대기 상태를 포함한 공장 수신기 백업, 서버의 접수·확인 이력 백업/복구.
