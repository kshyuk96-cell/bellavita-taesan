# 태산이 원장 편집·개발 연결

목표는 대표의 요청과 승인에 따라 원장의 데이터·수식·서식 및 연결된 Apps Script를 개선하는 것이다. 일반 직원의 기존 권한을 일괄 확대하지 않는다. 승인 기록과 실제 Google 인증은 서로 대체할 수 없다.

## 서로 다른 연결

|대상|필요한 실제 연결|완료 판단|
|---|---|---|
|셀 데이터·명시한 수식|태산이 서버의 실제 Google 계정, 대상 원장 편집 권한, Sheets API|수정 전 대상 대조 및 수정 후 재조회|
|서식·유효성 검사·탭 구조|Sheets API의 해당 변경 처리기, 보호 범위 확인, 정확한 변경 승인|지원하는 처리기의 실제 응답과 재조회; 셀 쓰기 권한만으로 완료 취급하지 않음|
|Apps Script 소스·HTML·설정|소유자가 승인한 사용자 OAuth, Apps Script API 및 프로젝트 접근 허용|전체 소스 백업, 승인한 변경 저장 후 전체 소스 재조회|
|함수 실행·배포·트리거|별도 실행 연결과 해당 실행 범위|소스 저장과 구분해 실제 실행 결과 확인|

공식 문서: https://developers.google.com/apps-script/api/how-tos/enable 및 https://developers.google.com/apps-script/api/how-tos/execute . `scripts.run`에는 공통 표준 Cloud 프로젝트·적절한 사용자 OAuth·API 실행 배포가 필요하며 서비스 계정을 사용할 수 없다. 시트 서비스 계정의 편집 권한을 높여도 이 조건은 충족되지 않는다.

## 이번 개발 경로

- `ledger_access.py --diagnose`: 서버가 실제 사용하는 인증 계정을 확인하고 원장 파일의 `capabilities.canEdit`를 읽는다. 미설정·읽기 실패는 미확인이다. 편집 가능 관측은 실제 수정이나 보호 셀 편집 성공의 증거가 아니다.
- 대표 계정의 카톡 `원장 권한 확인`: 모델 호출 없이 같은 진단을 실행한다. 대기 및 실행 시 권한을 검사하고, 권한이 회수되면 결과를 표시하지 않는다. 완료된 예전 진단을 새 결과로 재사용하지 않는다.
- `ledger_patch.py`: 명시한 셀의 값·명시한 수식에 대한 제한된 수정 처리기. 전체 시트 개발 기능을 완료했다고 간주하지 않는다.
- `/staff-orders/ledger-patch`: 기존 직원 웹 로그인 중 대표 계정만 사용한다. 요청 출처를 확인하고 준비/적용을 구분한다. 클라이언트가 대상 파일이나 권한을 정할 수 없다. 처리 전 기록은 `TAESAN_DATA/ledger-edits.sqlite3`에 보관한다.
- `script_project_access.py`: 고정한 사본/운영 프로젝트의 승인된 소스 변경 처리기. 사본 테스트 근거와 정확한 변경 승인을 대조한다. 저장 성공은 실행·트리거 설치·운영 배포 성공과 다르다.

운영 프로젝트의 소스를 저장하면 기존 트리거나 이벤트가 새 HEAD를 사용할 수 있다. 별도로 실행 API를 호출하지 않았다는 결과는 트리거 영향이 없다는 뜻이 아니다. 운영 승인과 사본 테스트 근거에는 기존 트리거 영향 검토를 포함해야 한다.

서버 연결 값은 `TAESAN_ORDER_SHEET_ID`(없으면 `TAESAN_SHEET_ID`), `TAESAN_GOOGLE_CREDENTIALS`, `TAESAN_SCRIPT_PROJECT_ID`, `TAESAN_SCRIPT_TEST_PROJECT_ID`, `TAESAN_SCRIPT_GOOGLE_CREDENTIALS`로 구분한다. 마지막 값은 소유자가 최초 동의한 사용자 OAuth의 전용 비공개 인증 파일 경로이며, 키나 토큰 내용을 환경 진단·PR·채팅에 출력하지 않는다. Google 최초 동의·Cloud API 활성화·파일 편집자 공유는 이 코드 작성만으로 완료되지 않는다.

일반적인 문장을 모든 원장 수정으로 변환하는 연결, 서식·탭 구조 변경 처리기, 개발 에이전트 실행 연결은 별도 통합이 필요하다. 지원하지 않는 작업은 승인되더라도 실행 완료로 보고하지 않는다.

현재 셀 처리기는 서버가 지정한 원장 탭의 명시한 범위만 지원하며, 한 요청은 최대 100셀·20행·20열이다. `TAESAN_LEDGER_TAB`이 기본 탭이고, 다른 탭은 서버의 `TAESAN_LEDGER_ALLOWED_TABS`에 정확한 이름으로 등록해야 한다. 이 허용 목록도 대상 파일의 실제 탭 메타데이터와 대조한다. 문자열은 문자 그대로 저장하고 수식은 `{"formula":"=..."}`로 명시해야 한다. `prepare`는 변경 전 대상과 행의 지문을 읽어 주는 단계이며, 실제 적용은 로그인한 대표의 별도 `apply` 요청에서 수행한다. 화면 전체·모든 탭·서식·유효성 검사·탭 추가/삭제가 한꺼번에 지원된다는 의미가 아니다. 실제 원장이나 다른 탭에 대한 지원을 확장할 때는 정확한 대상과 지원하는 변경 종류를 다시 확인한다.

Apps Script 소스 저장은 운영으로부터 격리된다는 뜻도 아니다. `updateContent`로 저장한 최신 소스는 기존 simple/installable 트리거와 편집기 실행에서 이후 사용될 수 있다. `executed:false`·`deployed:false`는 이 처리기가 직접 함수 실행·배포 API를 호출하지 않았다는 뜻이며, 기존 트리거가 새 소스를 나중에 실행하지 않는다는 보증이 아니다. 승인 패키지에는 기존 실행 경로의 영향과 필요한 중지·복구 절차도 포함해야 한다. 같은 프로젝트를 수정하는 실행기는 별도로 직렬화해야 한다.

## 운영 연결 전 확인

1. 원장 공유 목록의 계정 후보를 서버 계정이라고 추정하지 않고, 실제 서버 진단과 대조한다.
2. 검증된 계정에 대상 원장의 편집 권한을 부여하고 실제 보호 범위를 확인한다. 공개 공유나 다른 직원 권한을 확대하지 않는다.
3. 실제 서버에 설정한 원장과 사본, Apps Script 프로젝트, OAuth 대상이 올바른지 확인한다. 토큰·키는 채팅·로그·Git에 기록하지 않는다.
4. 임시 데이터 및 모의 제공자로 테스트하고, 이후 실제 사본에서 수정·중복 요청·권한 회수·실패·복구를 확인한다.
5. 승인된 변경만 운영에 적용하고 재조회한다. 데이터 기록의 영구 경로 및 재시작 보존을 확인한다.

시트 API에는 이 처리기가 사용하는 원자적 비교 후 수정 기능이 없다. 수정 직전 대조와 서버 잠금으로도 외부 수동 편집과의 경합을 완전히 없앨 수 없으므로 불일치는 중지 또는 결과 미확인으로 보고한다. 시간 초과 후 자동으로 같은 쓰기를 반복하지 않는다.

셀 수정 잠금은 같은 호스트의 같은 영속 감사 경로를 사용하는 실행기 사이에서 적용한다. 다른 호스트나 Google 편집 화면 전체를 잠그는 기능은 아니다. 이전 쓰기가 `checking`·`submitting`·`uncertain` 상태로 남으면 새 요청 ID로 재실행을 우회하지 않고 이전 원장과 감사 기록을 먼저 대조해야 한다. 원격 반영 확인과 미확인 기록의 해제를 자동으로 처리하는 복구 연결은 별도 검증이 필요하다. 감사 DB에는 요청한 셀 값과 재조회 값이 들어갈 수 있으므로 비공개 영속 경로·파일 권한·보존/복구 절차를 확인하고 공개 로그나 Git에 올리지 않는다.

현재 개발 작업에서 운영 원장 수정, 공유 권한 변경, Google 인증 생성, 서비스 배포 및 실제 발송을 실행하지 않았다. 실제 연결과 사본 시험이 남아 있는 부분은 개발 테스트 통과와 구분해 보고한다.

## 이번 검증의 실제 범위

격리된 로컬 서버에서 실제 `agent.py`를 시작해 HTTP `/healthz`를 확인했다. `env -i`, 별도 임시 `TAESAN_DATA`, 가상 관리자/직원과 존재하지 않는 fixture 인증 파일 경로를 사용했다. 가상 관리자의 `원장 권한 확인`은 실제 인증 정보 미연결을 미확인으로 안내했고, 가상 직원은 진단을 거부했다. 이 시험은 운영 ADC·서비스 계정·Google 원장에 대한 권한 확인이나 실제 셀 쓰기 성공의 증거가 아니다.

Python 3.12에서 `python -m unittest discover -s tests -q` 전체 88개와 `git diff --check`가 통과했다. 실제 사본의 편집·붙여넣기·수식 계산·Apps Script 실행 시험과 구분한다. 고정 후보 SHA는 커밋 완료 후 PR에 기록한다. 실제 Apps Script 사용자 OAuth·사본 프로젝트·승인 영수증 검증·외부 Git 밖의 영속 백업 연결이 없으면 소스 적용은 미연결로 남긴다.

소스 변경 처리기는 기존 이름·형식의 파일 수정만 지원한다. 파일 추가·삭제, `scripts.run`, 배포·트리거 설정은 아직 지원하지 않는다. 프로젝트별 잠금은 같은 프로세스의 동시 작업을 직렬화하며 외부·다른 프로세스 편집을 막지는 못한다. `TAESAN_LEDGER_ALLOWED_TABS`에는 서버가 검증한 기존 탭 이름을 쉼표로 설정하며 기본은 `TAESAN_LEDGER_TAB` 또는 `액자화환` 한 탭이다.
