사용자가 직접 처리하는 설정을 기다리는 대신 가능한 개발·사본 검증을 진행한다.

## 다음 진행 제안: 두 건 묶음

1. **백엔드 연결형 테스트 샘플**: 현재 상품 5종의 주문을 독립 테스트 서버에 저장하고
   관리자·고객 상태 조회·샘플 이미지가 같은 주문번호를 사용하도록 연결한다.
   완료 기준은 새로고침·재접속 후에도 테스트 주문과 배송 상태가 유지되는 것이다.
   결제·발송·영수증은 모의 공급자로 유지해 실제 과금·운영 데이터를 건드리지 않는다.
2. **부분취소 후 운영 처리 완결**: 잔액과 취소 이력을 대조한 관리자가 제작·배송 보류를
   유지하거나 재개할 수 있게 하고, 결정자·시각·근거를 남긴다.
   완료 기준은 부분취소 주문이 무조건 멈춘 채 남지 않고, 승인한 잔액·범위로만 한 번 재개되는 것이다.
