## 오류와 해결

- 정정 상태 연결의 들여쓰기 오류를 컴파일에서 발견해 수정했다.
- 정정 보류 이벤트에 변경 번호가 있으면 수신기의 재개 조건까지 만족해 보류가 풀렸다.
  ready/resume에만 재개 조건을 적용하고 같은 시나리오로 재검증했다.
- 기존 링크 호환 테스트가 사진 필드까지 바꿔 신규 링크가 생기는 정상 동작을 메타데이터 문제로 판단했다.
  실제로 메타데이터만 없는 기존 링크로 테스트를 분리해 통과했다.
- 리허설의 두 번째 가격 통보를 93,500원으로 보내 서버가 거절했다. 서버 계산 금액을 사용하도록 수정했다.
- 모의 영수증 번호가 실제 숫자 규격과 달라 결과 불명 처리됐다. 올바른 합성 숫자로 고친 뒤 발급을 확인했다.
- 정정 검토 중 취소 안내가 함께 보류될 수 있어 취소 알림을 분리하고 검증했다.

실제 운영 가맹점/국세청/단말 수신/프린터/운영 시트 검증은 수행한 것으로 기록하지 않는다.
