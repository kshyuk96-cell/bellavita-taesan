| 번호 | 기능 | 동작 |
|---|---|---|

| 9 | 업무별 매뉴얼 | 주문·상품·배송·정산·운영 설정에서 해당 관리 매뉴얼 절로 이동 |
| 10 | 주문 상세 빠른 이동 | 핵심 정보·설치 정보·접수/결제 기록·업무 이력·담당 업무·인수인계 영역으로 이동하고 접힌 영역 열기 |

## 저장·만료 동작

변경 내용은 localStorage/sessionStorage·쿠키·임시 파일로 저장하지 않는다. 페이지 이탈 경고는 자동 저장·복원 기능이 아니다. 브라우저나 모바일 운영체제가 경고를 생략할 수 있다. 파일 선택도 파일명을 기준으로 변경 여부를 알릴 뿐 파일 내용을 저장하지 않는다.

정상 저장에는 이탈 경고를 띄우지 않는다. 제출 버튼의 name/value가 있으면 전달값을 보존한다. 뒤로 가기로 페이지가 복원되면 화면의 저장 잠금을 해제하고 만료 상태를 다시 확인한다. 응답을 기다리는 동안 자동 재요청하거나 임의의 시간 뒤 저장을 다시 실행하지 않는다. 서버의 버전 검증·권한·중복 보호는 그대로 유지한다.

만료 2분 전부터 새 관리자 링크 준비를 안내한다. 만료 후에도 입력란을 지우거나 자동 이동하지 않고 확인·복사를 허용한다. 저장과 CSV 다운로드 확인은 차단한다. 대표 카카오에서 ‘쇼핑몰 관리’를 다시 요청하도록 안내하되 새 인증 링크를 자동 발급하거나 기존 링크를 연장하지 않는다. 화면 시간은 안내용이며 최종 권한·만료 판정은 서버가 수행한다. 오래 열린 탭과 실제 네트워크 지연으로 표시와 서버 판정에 차이가 있을 수 있다.

## CSV 선택과 개인정보

현재 검색이 적용된 상태에서 CSV를 누르면 조회 시점 건수와 조건을 보여준다. 새 주문·상태 변경으로 실제 다운로드 건수는 달라질 수 있다. 10,000건 제한과 관리자 서명 검증은 다운로드 시 서버에서 다시 적용한다.

`columns` 쿼리는 정해진 열 이름만 허용하고 주문번호를 필수로 포함한다. 선택 순서를 임의 SQL로 사용하지 않으며 파일 열은 정해진 순서로 정렬한다. 열 선택을 생략한 기존 직접 다운로드는 기존 13개 열을 유지한다. 명시적으로 빈 columns를 보내면 전체 항목으로 확대하지 않고 거부한다. 연락처 열은 선택해도 가림 상태이며 수식 방지와 `private, no-store` 응답을 유지한다.

전화번호 재가림은 화면 편의·노출 감소 기능이다. 인증된 관리자에게 전달된 원문을 HTML에서 제거하거나 별도 접근 권한으로 바꾸는 기능은 아니다. 단축키·매뉴얼·상세 이동은 주문이나 결제 상태를 바꾸지 않는다.

## 통합 파일

- `shop_admin_guard.js`: 미저장 비교, 저장 잠금, 만료 안내, 검색 미적용, CSV 확인 모달·열 선택, 단축키, 주문 내부 이동.
- `shop_admin_review.js`: 기존 연락처 표시 동작에 60초·탭 숨김 재가림 추가.
- `shop_admin_layout.py`: 서버 시각·만료 정보와 업무별 매뉴얼 링크 제공, 공용 스타일·JS 삽입.
- `shop_admin_review.py`: CSV 열 허용 목록과 서버 측 선택·투영 처리.
- `shop_admin_manual.py`: 화면과 같은 Markdown 절 목록에서 실제 매뉴얼 앵커를 찾아 연결.
- `agent.py`: 주문 CSV에 한해 빈 쿼리 값을 보존해 명시적 빈 열 선택을 거부. 다른 내보내기 파싱은 기존 동작 유지.
- JS 두 파일을 레이아웃과 함께 배포한다. DB 스키마·데이터 이전·외부 계정 설정은 추가하지 않는다.


독립 합성 데이터에서 새 서버 테스트와 모바일 390px·PC 1280px 브라우저를 실행한다. 가상 시간을 사용해 60초 재가림·2분 전 안내·만료를 확인한다. 필수값이 유효한 폼도 만료 뒤 요청이 나가지 않는지, 실제 서버는 유효한 서명이라도 만료됐으면 CSV·매뉴얼을 거부하는지 구분해 검증한다.

저장 연속 실행은 합성 직원 번호 설정 요청이 한 번만 도착하는지 확인한다. 주문 상태·원본 details 전후 값은 동일하고, 만료 차단 시험에서 새 업무가 등록되지 않아야 한다. CSV는 70개 합성 주문에서 선택한 열만 포함되는지 대조한다.

발견한 서버 오류: `columns=`를 파싱할 때 빈 값이 누락돼 기본 전체 열로 처리됐다. 주문 CSV에 한해 빈 값을 보존하고 서버에서 거부하도록 수정했으며 동일 요청으로 재확인했다. 잘못된 열·중복 열·주문번호 없는 선택도 거부한다.

상세 근거: [3차 검증 기록](validation/admin-batch-03.json). 실제 결제·알림톡·현금영수증·운영 원장·운영 데이터 검사는 이번 결과에 포함하지 않는다.

최종 결과: 전체 회귀 187개(88.251초), 새 서버 검증 3개, 새 390/1280px 브라우저와 기존 2차·일일 업무 브라우저가 통과했다. 비활성 버튼 표시 보완 후 새 브라우저를 다시 통과했다. JavaScript 오류·가로 넘침이 없었고 주문 상태·원본 details가 유지됐다. 서버 배포는 하지 않았다.
