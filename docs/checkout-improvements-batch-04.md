## 통합 계약

`checkout_guidance.js` → `checkout_preflight.js` 순서로 공용 HTML에 삽입한다. `checkout.py`가 두 파일을 읽어 기존 템플릿에 삽입하며 별도 정적 경로나 새 외부 서비스는 필요 없다. `checkout.html`의 `data-base-price`, `data-event-time`, `data-server-now` 속성을 함께 적용한다. `window.BellavitaCheckoutGuidance`는 기존 모듈의 DOM·필드 조회·안전한 노드 생성·수정 포커스·렌더 갱신 함수를 받아 보조 기능을 구성한다.

기존 `bellavita:checkout-reset` 처리와 함께 안내·오류·금액 차이·주소 길이를 초기화한다. 초대장 모바일 3단계 구조를 유지하며, 필수 표식과 오류 안내는 접힌 단계에도 별도로 연결한다. 금액 내역 안의 문자열은 textContent로 처리한다.

화면 계산·카운트다운은 안내이며 서버의 옵션·금액·설치 정보·행사일 검증을 대신하지 않는다. 기기 시간대와 무관하게 행사 입력을 +09:00으로 해석한다. 날짜 안내는 서버 렌더 시각과 브라우저 경과 시간을 사용하지만 최종 주문 가능 여부는 서버에서 다시 확인한다. 자동 저장·실결제·실발송·영수증 발급은 추가하지 않는다.
