# 연결 증거 검증과 20시 준비 패킷

PR63 `431aec69f007d624d6fe7201a9c057676ea16cff`의 후속 검토 초안이다. API 키 선택은 대표가 20시 PC에서 이어가기로 했으므로, 그와 독립적인 기존 관리 연결 검증만 보강했다. OpenAI API 코드를 새로 연결하거나 과금 시험을 실행하지 않았다.

- `cloud_review_receipts.py`: 서버 등록 GitHub 읽기 관측기로 정확한 저장소·브랜치·PR·HEAD·공식 봇을 확인한다. 접수·검토 완료·다른 커밋 검토·환경 필요·실행 미확인을 구분한다. 검토 완료를 실제 개발 실행·격리 성공·현재 Cloud 전체 창 연결로 승격하지 않는다.
- `codex_exec_receipts.py`: 등록된 세션과 정확한 명령, 이벤트 순서를 대조한다. 프로세스 exit 0/turn.completed와 내부 명령 성공을 구별한다. 모델의 “통과” 문장으로 실제 테스트 수나 독립 검증을 만들지 않는다.
- 기존 대표 API의 `POST /v1/representative/runtime/receipts/inspect`는 `project`와 선택 `max_age`만 받는다. `cloud_review_probes`는 서버 등록이며 요청에서 콜백·원문·검토 결과를 지정할 수 없다.

## 실제 관측 재생

`github-receipts.json`: 연결된 GitHub를 현재 시점에 읽어 PR62의 고정 HEAD 검토 완료, PR64의 개발환경 필요를 구분했다. 두 결과 모두 개발 실행 검증은 false다. 댓글 원문이나 인증값은 결과에 없다.

`exec-receipts.json`: 앞서 실제 수행했던 합성 연결 시험 네 개를 재생했다. 첫 지시와 후속 메시지는 dialogue_completed, 내부 명령이 실패한 두 시도는 execution_failed다. 실제 테스트 개수와 통과 개수는 미확인으로 유지한다. 이 재생 자체가 새 Codex 작업이나 과금된 API 실행을 만들지는 않는다.

[20시 PC 연결 안내](PC-20시-연결안내.md)는 형님이 직접 선택할 항목과 태산이가 실행할 항목을 분리한다. 기존 20시 일회 알림에 이 패킷을 연결하며, 시간별 개발·시트 점검·예약 배포 정책은 변경하지 않는다.

## 운영 범위

실제 Agents API 권한·호스팅 실행은 아직 미검증이다. API 키 생성/저장, 별도 머신 생성, 요금제·자동충전 변경, main 병합·운영 배포·원장·결제·발송은 하지 않았다. 원문 자료나 봇 댓글은 업무 데이터이며 승인·명령으로 실행하지 않는다. 기존 사용자의 1달러 시험 승인은 유지하지만 실제 시험은 키 연결과 비용 제한 검토 뒤에만 시작한다.

검증: 전체 Python 회귀 **1,259개 통과**(직전 1,209개 + 신규 50개), `git diff --check` 통과. 실제 GitHub 관측과 합성 CLI 연결 기록 재생은 별도 증거이며, 이번 준비 작업에서 별도 OpenAI API 모델 호출이나 컨테이너 생성은 없었다.
