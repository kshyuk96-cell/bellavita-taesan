# 관리자 일일 업무·교육 검증

한국 시간 오늘/이번 주(월~일)/앞으로 7일 행사 검색 링크, 주문별 담당자·기한 업무와 전체 미처리·기한 초과 현황/검색, 승인된 정정을 반영한 고객용 요약 복사, 상품 옵션 중복·형식·최대 금액 입력 검사, 다섯 가지 직원 교육 모의 시나리오를 추가했다.

업무 담당자는 배송 배정과 별도이며 업무 완료가 결제·제작·배송을 바꾸지 않는다. 요청번호와 버전으로 중복·동시 수정을 막고 변경 이력을 보관한다. 고객 요약에는 내부 메모·직원 정보·고객 전화번호·관리자 링크를 포함하지 않는다. 전체 취소와 부분취소가 함께 기록돼도 원금액을 초과해 취소 합계를 표시하지 않는다.

교육은 브라우저의 고정 가상 데이터만 사용한다. 실주문·결제·알림·영수증·실배송을 생성하지 않으며 새로고침으로 초기화된다. 교육 완료는 실제 직원 권한이나 업무 승인을 부여하지 않는다.

전체 회귀 149개와 집중 5개가 통과했다. 한국 시간 주간 경계, 기한과 동일 분/1분 초과, 업무 충돌·타 주문 수정 거부, 승인 문구와 요약 정보 범위, 상품 잘못된 저장 시 원본 보존, 만료된 교육 링크 거부를 확인했다.

375/1280px Chromium에서 행사 빠른 검색, 업무 등록→기한 초과/담당자 검색→완료→바로 열기, 요약 복사 미지원 대체 선택, 옵션 중복·음수 추가금 입력 검사, 교육 다섯 사례의 오답·정답·초기화를 확인했다. 교육 중 POST 0건, 실제 주문 증가 0건, JavaScript 오류·가로 넘침 없음. 기존 저장 검색·인수인계·상품 비교·매뉴얼과 네 상품 주문서 회귀도 통과했다.

Render 검증 환경 배포 결과는 `docs/validation/shop-admin-daily.json`에 추가한다. 운영 병합·실거래·실발송·실제 영수증·운영 원장 쓰기는 실행하지 않았다.
