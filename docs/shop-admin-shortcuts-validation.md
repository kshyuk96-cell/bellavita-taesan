# 관리자 빠른 처리·즐겨찾기·다운로드 검증

업무 빠른 완료/다시 열기, 관리자 공유 응대 문구 즐겨찾기, 상품 내부 메모 120자 요약, 관리자 권한의 교대 요약 텍스트 다운로드, 기능 이름으로 위치를 찾는 검색을 추가했다. 매뉴얼 25~29절과 함께 갱신한다.

빠른 처리도 기존 업무 변경 검사를 재사용한다. 요청 버전과 현재 상태를 대조하며 기존 제목·담당자·기한·우선순위·메모를 유지하고 변경 이력을 보관한다. 재열기 시 미처리 30개 한도를 적용한다. 결제·제작·배송은 바꾸지 않는다.

즐겨찾기는 서버의 공유 설정이며 변경 버전·이력을 남긴다. 사용 중인 문구만 주문에 표시하며 첫 선택과 미리보기 내용을 일치시킨다. 메모 요약은 관리자에만 표시한다. 교대 파일은 같은 담당자·기한 조건과 100개 제한을 재사용해 다운로드 시점에 생성하고 기존 관리자 서명/만료를 검사한다. 내부 근거가 포함된 UTF-8 텍스트이며 비공개·캐시 금지 헤더를 적용한다.

기능 검색은 고정된 기능 이름·설명에서 결과 최대 10개를 제공한다. 필요한 펼침 항목을 열고 위치로 이동하며 저장·완료·발송 동작을 실행하지 않는다. 저장 검색·직원 교육·알림 설정은 해당 영역으로 이동한다.

회귀 160개와 최종 집중 5개를 통과했다. 빠른 완료/재열기·중복·타 주문 수정 거부·미처리 한도, 즐겨찾기 순서/초기 문구/이력, 메모 요약 길이·이스케이프·비공개·빈 메모, 파일 조건·만료 권한·데이터 불변을 확인했다.

375/1280px Chromium에서 빠른 완료/재열기, 새 접속에서도 공유 즐겨찾기 반영, 메모 요약/펼침, 기능 검색의 이동·빈 결과·POST 없음, 실제 텍스트 다운로드를 확인했다. JavaScript 오류·가로 넘침 없음. 기존 팀 관리자·일일 업무/교육과 네 상품 주문서도 통과했다. 적용 전 독립 검증 데이터 백업·임시 복구를 통과했다.

배포·재배포·복구 결과는 `docs/validation/shop-admin-shortcuts.json`에 추가한다. 운영 병합·실거래·실발송·실제 영수증·운영 원장 쓰기는 실행하지 않았다. 비밀키·서명 URL·외부 백업 식별자는 공개 기록에 넣지 않는다.

독립 Render 서버에 `9469e8b` 배포 후 모의 업무의 빠른 완료/재열기와 공유 즐겨찾기를 저장했다. 같은 코드로 재배포한 뒤 업무 상태·버전과 즐겨찾기 보존, 첫 문구/미리보기 일치, 담당자 조건을 적용한 내부 텍스트 다운로드 헤더·내용, 메모 요약·기능 검색 제공, 기존 주문 3건의 결제 대기·취소 상태 유지를 확인했다. 영구 디스크·SQLite 무결성, 즐겨찾기 두 테이블의 백업·임시 복구 건수 대조와 매뉴얼 원본 일치도 통과했다.
