# 대화의 사진·음성 입력과 짧은 응답

기존 `taesan_core.adapters.Media`를 재사용한다. 실제 이미지 모델이나 음성 인식 제공자는 아직 연결하지 않았다. 이 변경은 음성·사진을 업무 도구와 연결하는 경계와 모의 시험이며, 카카오 기기 수신 또는 실제 인식 정확도 검증이 아니다.

`prepare_media(principal, attachments, question, media=None)`는 현재 인증된 `Principal`과 동의된 `Attachment`의 tuple만 받는다. 빈 tuple은 텍스트 요청으로 처리하며, 1~5개 사진/음성은 이미 호스트가 안전하게 받은 bytes여야 한다. URL을 내려받거나 임의 파일을 읽는 기능은 없다. 잘못된 첨부가 하나라도 있으면 제공자 호출 전 전체를 거부한다.

호스트가 등록한 Media의 image/audio 콜백은 `(principal, content_bytes, accompanying_question)`을 받아 기존 `Extracted`를 반환한다. 반환된 `MediaContext`는 현재 질문을 `user_question`, 해석 결과를 `untrusted_material`로 분리한다. 사진·음성 속 승인이나 명령은 계정 권한·사용자 확인·실행 증거가 아니다. 원본 bytes/예외 본문을 응답이나 로그에 쓰지 않는다. 본 모듈에는 저장소와 로거가 없다.

**계획 또는 도구 호출 전에 `media_gate(context)`를 적용한다.** 첨부 중 하나라도 미연결·실패하면 실제 실행이 시작되지 않은 고정 한국어 응답을 돌려준다. 일부 사진만 읽혔더라도 전체 업무를 추정 실행하지 않는다. 정상 해석은 제안 입력이 될 수 있을 뿐 처리 완료 근거가 아니다.

`render_reply(reply, project, action=None)`는 기존 Core의 `Reply`에서 등록된 상태·검증된 건수·필터 날짜/상태·최대 세 개 자료 번호·현재 시트/API의 알려진 상태·조회 시각만 짧게 표시한다. 고객 이름·전화·주소·상주 정보와 외부 제공자의 자유 문장을 출력하지 않는다. 실제 0건, 미연결, 권한 부족, 근거 불명확을 구별한다. 조회 결과의 취소/배송완료 상태를 표시할 수 있지만 이번 요청이 취소/배송 처리를 실행했다고 말하지 않는다.

모의 시험은 질문과 사진 동시 전달, 음성의 승인 문장, 미연결/예외/부분 실패 차단, 인증과 동의 선검사, 실제 0건 및 누락된 건수, 안전한 한국어 상태 설명을 다룬다. 실제 직원 음성·사진 인식률과 운영 태산이 점수는 별도로 측정해야 한다.
