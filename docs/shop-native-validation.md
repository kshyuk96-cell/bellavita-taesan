## 발견하고 수정한 사항

- 기존 상품 편집기가 원본의 51/52개 작품 옵션과 여러 묶음을 보존할 수 없어 묶음별 편집으로 확장했다.
- 기존 행사 링크 발급은 세 번째 옵션을 받는 분으로 가정해 덮어썼다. 이름으로 받는 분 묶음만 변경하도록 수정했다.
- 신규 대표 상품 주문에도 쌀빛 주문서 제목·상세설명이 표시돼 해당 상품의 제목/원본 상세로 분리했다. 기존 초대장 내용은 유지한다.
- 모바일 상품 사진이 중첩 갤러리에서 작게 표시돼 직접 배치로 수정하고 화면을 재검증했다.
- 모의 결제 페이지의 전체취소 상태를 공식 규격의 승인취소 64로 수정했다. 32는 요청취소로 유지한다.
- 테스트 가맹점 번호가 두 주문에 중복 배정되는 테스트 픽스처를 수정했다. 실제 유일 결제번호 제한은 유지한다.
- 샌드박스 기본 테스트는 로컬 소켓 권한으로 실패해 허용된 확장 실행에서 재실행했다. 코드 오류로 간주하지 않았다.

실결제·실제 가맹점 취소/영수증·알림 단말 수신·운영 시트 쓰기·실제 출력은 수행하지 않았다. 같은 디스크의 로컬 백업을 외부 재해복구 백업으로 주장하지 않는다.
