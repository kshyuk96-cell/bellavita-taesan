# 다음 승인 제안101–120 — 미착수

이번 검증은 source Worker의 재시작이다. 다음은 부모 controller 장애·키 전달·DB 복원 일관성과 권한을 먼저 다룬다. 운영 배포·실제 공급사/PG·발송·유료 자원은 제외한다.

|번호|개선 개발|완료 기준|
|---|---|---|
|101|분리된 TEST key broker 계약·메모리 provider|controller 종료 뒤에도 승인된 작업에만 key를 stdin 전달|

|103|부모 QA controller 강제 종료 검사|running job 보존·자식 존재 대조·자동 재실행 금지|
|104|종료 증명 저장 전후 장애·Docker 조회 실패|살아 있거나 확인 불가한 실행자를 stopped로 표시하지 않음|

101–116은 승인된 로컬 비운영 자원과 simulator로 검증한다. 실제 외부 secret 서비스·원격 중앙 서버·공급사·PG 연결은 이 제안의 자동 실행 대상이 아니다. 118–119는 지원 CUA가 없으면 준비 검증과 미실시 표시만 수행하며, 브라우저 설치나 임의 대체 조작 경로를 사용하지 않는다.
