# 다음 20개 제안 — 실제 서비스 어댑터 연결

상태: **제안 / 미착수 / 사용자 승인 대기**. 번호 21~40은 첫 20개와 별도 개발 묶음이다. 운영 배포·실제 결제·유료 자원 생성은 포함하지 않는다. 실제 서비스 소스와 연결 코드를 준비하고 승인된 비운영 환경에서 검증한다. 접근/실행 경로가 없으면 그 항목은 연결 대기로 보고한다.

| 번호 | 제안 개발 항목 | 확인할 결과 |
|---:|---|---|
| 21 | 실제 서비스 어댑터의 소스·설정 버전 고정 | 다른 버전 결과 재사용 차단 |
| 22 | 실제 서비스 빌드·런타임의 격리 실행 프로필 | 준비 여부·실행 경계·제한 확인 |
| 23 | 기존 검수 도메인 함수에 연결하는 fixture bridge | 별도 참조 모델 대신 실제 서비스 코드 호출 |
| 24 | seed 전용 인증·프로젝트 범위 | 일반 회원/다른 실행의 데이터 주입 차단 |
| 25 | 테스트 테이블만 대상으로 하는 seed/reset | 운영·기존 고객 데이터 접근 없음 |

| 32 | 실제 테스트 로그인·역할·공간 분리 검사 | 본인/타 실행/관리 권한 구분 |
| 33 | 실제 서비스의 3등급 가입 시험 연결 | 초기 결제·원금·BP·활성화 비교 |
| 34 | 실제 U04/P02 원금 우선 혼합결제 시험 | 지정 금액·원장·재고·가상 승인 대조 |
