## 계약·격리·한계

관리기 기대값은 `hope_batch02.EXPECTED`에 사전 고정. 작업자가 보고한 expected/status/counts를 인수 근거로 사용하지 않는다. 20개 ID 누락·중복, 소스 불일치, 계약 하향을 거절한다. 브라우저 증거는 작업자가 PASS라고 해도 미검증으로 남긴다. 용어는 관리기에서 script/style/template을 제거한 HTML 본문으로 독립 대조한다.

세션 쿠키·setup key·암호화 키는 메모리에서만 사용, 보고서 trace는 경로·상태·요청ID만 기록. 설정 경로는 전용 SQLite 인증서가 있어야 생성 가능하며 실제 운영 바인딩에 설치하지 않는다. 등록은 비어 있는 새 실제 검수 공간에만 가능. 재준비는 세대·소스·CAS와 미확정 처리 검사를 통과해야 하며 자동 재시도하지 않는다. 컨테이너 타임아웃/오류는 불확실 실패로 거절한다.

실제 코드 실행은 Docker network-none/read-only/UID65534/권한삭제와 Node 파일·프로세스 권한 제한 내에서만 한다. 호스트 대상 실행 fallback 없음. 호스트 rootless Docker는 cgroup 미지원: 하드 cgroup 메모리/CPU 제한을 주장하지 않는다. Node heap384MiB/CPU RLIMIT35초/파일64MiB/tmp128MiB/SQL약32MiB/시간90초/출력8MiB 제한을 사용한다. 프로세스 총 메모리 하드 제한이 필요한 호스트에서는 이 프로필을 승인하지 말고 지원 호스트로 옮긴다.

원래 Worker를 빌드해 Request/Response 직접 호출한다. 호환 SQLite 계층은 실제 Cloudflare D1 검증이 아니다. 모든 카드·환불은 실제 서비스의 simulator; 외부 통신·발송·배포·실제 결제 없음. seed는 DP 직접 부여 대신 실제 납부/예약/완료 흐름으로 출처를 구성하고, 보너스만 TEST grant를 사용한다. 원금우선 및 9개 BP 상한·취소수수료0은 고객 예제 TEST 정책이며 운영 승인으로 사용하지 않는다.

브라우저 제한: [Sites SKILL.md](skill://plugin_connector_1p_689987207de08191979cf68eca2941c6/sites/SKILL.md)의 “If `cua_repl.js` is unavailable, skip browser QA” 지침 적용. 지원 도구가 없어 preview server/브라우저 설치/대체 조작을 실행하지 않았다. 준비한 검사 함수는 지원 브라우저 호스트의 인증·소스 일치 맥락에 연결할 후속 코드이며 실행 증거가 아니다.

## 중앙 관리기 회수

기존 관리기의 작업 접수/중복·한도/상태·수집 인터페이스는 #73/#74에 유지된다. 이번 묶음은 명시 등록된 실행 호스트에서 위 CLI를 실행하고 `common-report`와 `trusted-contract`를 기존 `admit_qa_report`로 판정하는 실행 어댑터다. 중앙 서버의 실제 원격 배선/인증키 설치는 미적용이다. report·contract 해시뿐 아니라 소스 SHA, 프로젝트, 작업ID, 어댑터 버전의 중앙 작업 envelope를 함께 확인해야 하며 이 로컬 CLI 결과만으로 원격 작업을 완료 처리하지 않는다.
