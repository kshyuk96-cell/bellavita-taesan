# 태산 AI · 카카오와 ERP 공통 연결 규약

태산 AI는 카카오와 ERP의 공통 업무 에이전트다. 채널은 입력·표시·인증을 담당하고, 공통 코어가 업무 해석·도구 선택·권한 검사·실행 근거·진행 상태를 처리한다. 카카오 코드를 복제해 ERP용 별도 판단 체계를 만드는 방식은 피한다. 현재 ERP 저장소/PR은 확인되지 않았으며, 이 문서는 연결 규약이지 ERP에 적용 완료한 증거가 아니다.

## 인증과 업무 경계

ERP 백엔드와 카카오 인증 어댑터가 검증한 계정에서 프로젝트, 사용자, 직원 역할, 대화 범위, 요청 대조 키를 정한다. 이 값을 모델 답변·첨부 이미지·질문 원문·브라우저 임의 role 필드에서 가져오지 않는다. 원본 토큰과 계정 비밀값은 프롬프트·업무 로그로 전달하지 않는다.

직원 업무 기능과 대표/관리자의 개발 기능은 구분한다. `manager_bridge`의 토큰·웹 세션·개발 승인 API를 직원 브라우저에 배포하지 않는다. ERP 관리자 영역이 명시적으로 해당 기능을 제공할 때도 ERP 서버의 권한 확인을 먼저 적용하고 별도 관리 연결 범위로 호출한다. Google/Apps Script 인증과 개발 관리 로그인을 서로 대체하지 않는다.

업무별 기준 원장은 기존 연결을 확인해 지정한다. ERP가 생겼다는 이유로 시트 데이터를 자동 이관하거나 ERP를 곧바로 최종 원장으로 가정하지 않는다. 동일 주문의 내부 식별/행 번호 매핑과 실제 내용을 확인하며, 직원은 기존 행 번호를 계속 사용할 수 있다.

## 요청과 실행

카톡 텍스트·사진·콜백과 ERP 텍스트·음성·첨부를 공통 요청 형식으로 변환하되, 실제 수신/동의/읽기 성공 여부를 별도로 남긴다. 원본 사진·개인정보·질문 원문을 편의상 장기 저장하지 않는다. 태산이가 접근하지 못한 링크나 음성을 읽었다고 보고하지 않는다.

명확한 읽기는 인증된 도구로 조회하고, 누락된 필드만 같은 초안에 이어 묻는다. 대화 맥락은 같은 프로젝트·인증 사용자·현재 대화/업무 범위에만 재사용한다. 다른 직원·오래된 사진·새 업무로 맥락을 넘기지 않는다. 'ㅇㅇ'은 바로 앞의 정확한 미결 확인 범위에만 연결한다.

변경은 명시 요청, 담당 역할, 실제 실행 연결, 기능 플래그와 필요한 승인 범위를 서버가 검사한다. 모델이 실행을 선택했다는 이유로 쓰거나, 승인한 명세/후보가 바뀌었는데 기존 승인을 재사용하지 않는다. 실패/시간초과/콜백 중복은 대조 키와 실제 상태를 확인한 뒤 처리하고 미확인 변경을 자동 재실행하지 않는다.

## 결과와 화면

두 채널 모두 같은 업무 진행 상태와 근거를 사용한다. 0건·조회 실패·권한 부족을 구별하고, 실제 도구 응답과 재조회로 확인한 범위만 완료로 표시한다. 날짜·센터·상태·근거 시각을 필요한 만큼 짧은 한국어로 제공한다. 긴 명령어·접수 ID를 직원에게 반복 입력시키지 않는다.

ERP에서 표·버튼·이미지·엑셀을 제공하더라도 카카오에서 받을 수 있는 결과 범위와 콜백 지원 여부는 실제로 시험한다. 관리자 검토 화면은 요약을 먼저 보여주고, 커밋·파일·검토안 차이는 펼쳐 확인한다. 현재 관리 화면의 iframe 허용은 기본 차단이며 실제 ERP 호스트가 정해지면 동일 출처 통합 또는 제한된 허용 구성을 별도 검증한다.

## 실증 구분

개발 단위 테스트, 실제 관리형 개발 에이전트의 구현/검증, ERP 직원 사용, 카카오 실기기 사용, 운영 반영을 구분한다. 관리 모듈 테스트 통과를 직원용 대화 기능이나 운영 90점 실측으로 바꾸어 보고하지 않는다. 실제 ERP 연결 시 인증 사용자 범위·한 업무의 양 채널 조회·음성/사진 동시 입력·무권한 변경 거부·재시도 대조를 사본에서 먼저 재현한다.
