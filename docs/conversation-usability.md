## 연결 방법

호스트는 기존 `ConversationGateway`와 직원/대화 인증 콜백, 읽기 제공자를 등록해야 한다. 없으면 미연결로 반환한다.

- `POST /v1/representative/runtime/conversation/read`: 기존 필드 유지. 결과에 `snapshot_id`, 선택 가능한 경우 `choices`를 추가한다.
- `POST /v1/representative/runtime/conversation/export`: `project`, `channel`, `conversation`, `snapshot_id`. 재인증한 XLSX 첨부 반환.
- `POST /v1/representative/runtime/conversation/select`: `project`, `channel`, `conversation`, `request_id`, `selection_id`, `generation`. 최신 소스 조회·행 내용 대조 후 선택 항목 읽기.

본문의 역할·권한·계획·제공자·콜백·URL은 받지 않는다. 선택 토큰은 승인 권한이 아니다. XLSX/선택도 읽기 전용이다. 결과 스냅샷은 비공개 DB에서 최대 15분, 최근 두 개만 유지한다. 입력 자료는 명령 권한을 바꾸지 않는다.

모의 제공자를 사용한 단위/서버 경계/HTTP 검증 결과는 PR 본문에 기록한다. 실제 고객 ERP·카톡·음성·사진 검증 및 별도 API 연결을 완료했다는 의미가 아니다.
