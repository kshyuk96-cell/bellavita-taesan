# 관리자 완료·임박·교대 보관·운영 점검 검증

완료 업무 검색(같은 업무의 상태·담당자·우선순위 조합), 한국 시간 현재 분~24시간 뒤 같은 분의 기한 임박 표시·검색, 관리자 공유 기능 즐겨찾기 최대 8개, 변경되지 않는 교대 요약 보관·다운로드, 읽기 전용 설정 조회와 운영자 확인 기록을 추가했다. 매뉴얼 30~34절을 함께 갱신했다.

교대 보관은 저장 시점에 같은 조건으로 새 요약을 생성하고 요청번호로 중복을 막는다. 최대 200개를 보존하고 최근 20개를 표시한다. 기존 업무 변경과 별개이며 보관 파일은 관리자 서명·만료를 확인한다. 기능 즐겨찾기는 안정된 기능 식별자로 저장하고 버전·변경 이력을 보존한다. 기능 이동은 POST나 업무 처리를 실행하지 않는다.

운영 전 점검은 환경·가맹점·알림톡·현금영수증·디스크·백업·결제 확인 필요 건수를 비밀값 없이 읽는다. 외부 서비스 요청은 없다. 운영자 체크는 작성 시점의 확인 메모로 별도 보관하며 전부 체크해도 실가맹점 검증 성공이나 운영 활성화로 표시하지 않는다.

회귀 166개와 최종 집중 6개를 통과했다. 완료/임박 검색의 같은 업무 조건·24시간 경계·완료/초과 제외, 즐겨찾기 버전과 8개 한도, 보관의 불변성·중복·200개 한도·다운로드 권한, 운영 체크 후 결제/발급 비활성 상태 보존을 확인했다.

초기 브라우저 검증에서 교대 검색 필터와 보관 숨김 입력의 이름이 겹쳐 중복 선택이 발생했다. 보관 필드를 분리하고 같은 저장·다운로드 흐름을 다시 실행해 해결했다. 375/1280px Chromium에서 완료·임박 검색, 기능 즐겨찾기 재접속·이동(POST 없음), 점검 기록, 업무 완료 후에도 변하지 않는 보관 파일을 확인했다. JavaScript 오류·가로 넘침 없음. 기존 빠른 처리·문구 즐겨찾기·파일 다운로드·기능 검색·일일 업무/교육과 고객 네 상품 주문서도 통과했다.

독립 검증 데이터의 배포 전 백업·임시 복구를 통과했다. 배포·재배포 보존 결과는 `docs/validation/shop-admin-launch.json`에 추가한다. 운영 main 병합·실결제·실발송·실제 영수증·운영 원장 쓰기는 실행하지 않았다. 비밀키와 관리자 서명 URL은 공개 기록에 남기지 않는다.
