## 실제 연동 범위와 남은 설정

**실제 문자 전송·단말 수신, 실제 현금영수증 발급·국세청 반영은 수행하지 않았다.**
모의 SOLAPI/페이앱 응답과 로컬 검증용 서명 통보를 사용했다.
실제 MMS는 SOLAPI 계정·인증 발신번호·API 정보·잔액·직원 번호가 필요하다.
실제 현금영수증은 상품 과세 구분과 가맹점의 중복 발급 방지 확인이 필요하다.
설정·운영 순서는 [주문 알림·배송·현금영수증 안내](shop-order-operations.md)를 따른다.

카카오 비즈메시지 발송 어댑터는 구현하지 않았고 MMS로 구현했다.
기존 대표 본인 카톡 알림은 그대로 유지한다.
운영 Render 영구 디스크 경로·플랫폼 재배포는 이전과 같이 미검증이다.
이번 재배포 검사는 로컬 새 프로세스이며 Render 운영 재배포로 간주하지 않는다.
