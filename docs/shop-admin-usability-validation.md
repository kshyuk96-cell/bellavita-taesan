# 관리자 편의 개선 검증

전체 기록 검색(주문번호·사람·연락처·문구·상품·행사장), 결제/배송/행사일 복합 필터와 30건 페이지, 주문 요약의 다음 할 일, 주문번호·고객 상태 링크 복사, 저장 후 검색 조건·업무 위치 복귀를 구현했다.

관리 매뉴얼은 `docs/shop-admin-manual.md` 한 원본을 관리자 권한의 HTML·파일 다운로드로 제공한다. 검색·인쇄를 지원하며 관리자 링크와 같은 만료·권한을 적용한다.

회귀 138개, 최신 변경 집중 테스트 3개가 통과했다. Chromium 375/1280에서 복합 검색, 접힌 주문의 다음 할 일, 복사 미지원 대체 선택, 설정 저장 후 필터·위치 유지, 매뉴얼 검색·가로 넘침을 확인했다. 기존 상품/주문서와 관리자 운영 시나리오도 통과했다. 브라우저 검증용 리다이렉트는 실제 로컬 서버 주소로 처리한다.

독립 테스트 데이터만 사용했다. 운영 병합·실결제·실제 알림·현금영수증 발급은 실행하지 않았다. Render 검증 서버 배포 결과는 검증 JSON에 추가한다.
