# 주문 입력 시 중복 경고

`DuplicateOrderWarning.gs`는 액자화환 원장에 직원이 입력하거나 붙여넣을 때 같은 배송일(B), 설치장소(F), 보내는 분 요약(Q)을 가진 행을 찾습니다. 보내는 분 원문(P)이나 행사시간(C)의 차이로 경고를 숨기지 않습니다. 예를 들어 원문에 직함이 다르게 적혀도 Q에 기록된 이름과 배송일, 설치장소가 같으면 경고합니다. 배송일의 시간 성분은 시트 시간대 기준으로 제거합니다.

운영 적용 전 사본에 파일을 추가하고, 기존 `onEdit(e)`에서 배송일, 장소, 요약값을 반영한 뒤 `warnDuplicateOrderOnEdit(e)`를 한 번 호출하세요. 기존 편집 함수에서 P를 받아 Q를 채우는 경우에는 Q 반영 뒤에 그 행의 Q 범위도 이 함수에 넘겨야 합니다. 별도 편집 트리거를 추가하면 기존 자동화와 중복 실행될 수 있습니다. 가상 주문을 한 건 입력한 뒤 직함이 다른 같은 발신자의 두 번째 주문을 넣어 경고와 해당 행 번호를 확인합니다.

알림에는 행 번호만 표시하며 주문과 재고는 수정하지 않습니다. 시트에서 실제로 수정한 사람에게 보이는 화면 경고입니다. API나 다른 스크립트가 기록한 주문은 편집 트리거가 실행되지 않으므로 해당 등록 경로에 별도 연결이 필요합니다.

로컬 검증은 저장소에서 `node --test tests/test_sheet_duplicate_warning.cjs`로 실행합니다.
